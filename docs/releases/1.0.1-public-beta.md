## Privacy / temporary data

Room/private text and voice are temporary and expire by each message's own creation time. Durable backups intentionally exclude messages, voice storage, Telemetry, precise Nearby locations, active sessions and other short-lived state so a restore cannot resurrect expired chat content.

Telemetry is technical-only and bounded to 24 hours. It must not contain message contents, authentication tokens, full phone numbers or exact location.

## Optional features

TV, Store, paid features, Telemetry and Push are server-driven Feature Flags. If an optional integration has not passed Production QA, keep that feature OFF rather than blocking Core authentication/text/voice chat.

## Android release proof

The trusted release workflow requires external Android signing secrets, signs the APK, runs `apksigner verify --print-certs`, calculates APK SHA-256, and uploads the signed APK plus certificate and hash proof.

An unsigned CI release candidate is **not** the public APK.
